Software engineer and cloud architect with 19+ years of hands-on experience (12+ as a freelancer),
specializing in enterprise modernization and cloud-native transformation. Right now I am IT architect at

\section*{Ledger of Lessons}
\begin{itemize}
\item Technical competence does not automatically translate into leadership (wer-kennt-wen).
\item The familiar choice is not always the right one: Sphinx versus ElasticSearch.
\item The simplest approach is often superior: Pub/Sub on Azure Event Hubs.
\item Quality investment accelerates velocity (Saloodo!), and taking care of technical debt pays off (2026).
\item Separate operations teams create friction, which confirms ``you build it, you run it''.
\item Not knowing what works is an insight, too (BitterQuant).
\end{itemize}
