\item \textbf{Rewrote it, then questioned it:} The previous version had never gone live, so I rewrote it from scratch. After 580 commits and 77 releases, my lesson: the middleware was unnecessary, and AWS eventing or Lambda could have been cheaper and simpler.

\end{itemize}

\item \textbf{Microservices, lived experience:} Simple changes touched many services, with too little testing and automation. The architecture was not open to change, so I changed my mind instead: I have preferred Self-contained Systems ever since.
\item \textbf{Java on Lambda, because someone had to:} I evaluated Micronaut for AWS Java Lambdas and built a reusable Lambda template for the team. I also picked Twilio and shipped SMS delivery.
