\subsection*{Working Principles}
\begin{itemize}
\item \textbf{Paying down tech debt pays off}, and an autonomous, motivated team is gold. Union Investment confirmed both once again.
\item \textbf{You build it, you run it:} Every handover to a separate operations team costs communication effort and brings together different working styles.
\item \textbf{Self-contained Systems over microservices as the overarching architecture:} At Trusted Shops, simple changes spread across many services.
\item \textbf{Managed services before Kubernetes:} For simple applications in hyperscaler environments, more appropriate services exist.
\item \textbf{Simple, proven solutions:} A plain pub/sub Event Hub solved a search architecture that first seemed impossible.
\item \textbf{Integrated over separate:} At Saloodo, eventing with AWS Lambda in the AWS-based core would have been cheaper and more robust than a separate middleware.
\item \textbf{Technology by fit, not familiarity:} Choosing Sphinx over ElasticSearch at werkenntwen proved suboptimal; colleagues later migrated to ElasticSearch.
\item \textbf{Leadership is about people:} My first leadership role taught me the human factor. I moved toward a laissez-faire style that suits me and the team.
\item \textbf{Garbage in, garbage out, also for agents:} Engineering best practices and good developer and agent experience keep agent-built code maintainable.
\item \textbf{Realistic simulation first:} In BitterQuant, two promising approaches collapsed once execution was simulated realistically.
\end{itemize}
