\section*{Working Principles}
\begin{itemize}
  \item \kpi{Agent-first, engineer-owned:} agents write most of the code and tests; I own goals, architecture,
        review and the go/no-go -- with the same quality gates as for human-written code.

        reach production, document decisions transparently as ADRs.

        teams ship safely and often.
\end{itemize}
