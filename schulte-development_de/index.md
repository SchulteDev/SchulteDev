# About me

I modernize enterprise IT landscapes and stay hands-on while doing it. I work **agent-first**:
coding agents write most of the code under my supervision, I keep architecture, scope and quality
decisions.

## Core Expertise

- **Enterprise Architecture:** Legacy-to-cloud migrations on Azure, AWS and GCP, cloud-native
  system design, platform engineering
- **Cloud-Native Design:** Self-contained Systems (SCS), microfrontends, event-driven architecture
- **Technical Leadership:** Led teams of 5–9 developers as architect, technical Product Owner and
  mentor
- **Backend Engineering:** Java (19y), Go (5y), TypeScript – from monoliths to distributed systems
- **Agentic Coding:** Daily work with coding agents (Claude Code): parallel sessions, custom
  skills, hooks, automated agentic PR review
- **DevOps & Quality:** Infrastructure-as-Code, CI/CD, contract testing, automated dependency
  updates, quality gates

## Education

Diplom in Computer Science (equivalent to a Master of Science), University of Koblenz-Landau,
completed with distinction.
